# 일원배치분산분석 (One-way ANOVA)

**"세 개 이상 집단은 서로 얼마나 다르게 평가하고 있을까?"**

**"어떤 그룹이 특히 높거나 낮은 점수를 보일까?"**

일원배치분산분석(One-way ANOVA)은

**3개 이상의 집단이 서로 다른 평균을 가지고 있는지**를 판단하는 분석입니다.

예를 들어,

- 성별(3집단): 남성 / 여성 / 기타
- 연령대(5집단): 10대 / 20대 / 30대 / 40대 / 50대
- 소득수준(4집단): 저소득 / 중간 / 중상 / 고소득
- 영화관 이용빈도에 따른 만족도 차이

등과 같이 **집단이 3개 이상일 때**, 두 집단 비교(t-검정)로는 분석할 수 없으므로

ANOVA를 사용합니다.

- **핵심 개념:** 3개 이상 집단 간 평균 차이 검정
- **주요 지표:** F값, p값, 집단별 평균 비교, 사후검정(Post-hoc)
- **언제 사용하나요?:** “어떤 집단이 더 높은가?”, “특정 집단만 유독 낮은가?”를 알고 싶을 때

---

## 1. 왜 일원배치분산분석이 중요한가?

두 집단 비교(t-검정)만으로는 3개 이상의 집단 차이를 파악할 수 없습니다.

ANOVA는 다음과 같은 질문에 답합니다:

- 연령대별 만족도는 차이가 있을까?
- 고객 유형별로 불만족 수준이 다를까?
- 이용 빈도에 따라 추천 의향이 달라질까?
- 극장 방문 횟수에 따라 요금 만족도가 다르게 나타날까?

즉, ANOVA는 **전체 집단 간 차이를 한 번에 검정**하고

**어떤 집단이 높은지 / 낮은지**를 명확히 밝혀줍니다.

## 2. 비즈니스 활용 예시

| **분야**          | **활용 시나리오**               | **얻을 수 있는 인사이트**          |
| ----------------- | ------------------------------- | ---------------------------------- |
| **공공조사**      | 연령대별 행정서비스 만족도 비교 | 특정 연령대의 불만 원인 파악       |
| **고객 분석(CX)** | 이용빈도별 만족도 차이          | 충성 고객 vs 신규 고객의 격차 확인 |
| **제품 기획**     | 소비자군별 제품 평가 차이       | 시장 세그먼트별 니즈 파악          |
| **교육·훈련**     | 수강생 배경별 학습 만족도 차이  | 특정 그룹의 낮은 만족 원인 분석    |
| **HR 조직진단**   | 직무군·직급별 업무만족도 비교   | 조직 내 인식 격차 발견             |

## 3. 일원배치분산분석 옵션 가이드

### ① 독립변수(집단 변수) – 1개만 선택

- 단일 선택형 문항
- 집단은 **3개 이상**이어야 분석 의미가 있음
- 예: 연령대(5집단), 소득(4집단), 방문 경험 단계(3집단) 등

### ② 종속변수(분석 대상) – 1개 이상 선택 가능

- 평균 비교가 가능한 점수형 문항
- 여러 문항을 한 번에 분석할 수 있어 효율적

### ③ 사후검정(Post-hoc Test) 선택

ANOVA는 “전체적으로 집단 간 차이가 있다(p&lt;.05)”까지만 알려줍니다.

**어떤 집단끼리 차이가 있는지**는 별도의 사후검정으로 확인해야 합니다.

우리 시스템에서 제공하는 사후검정:

- **Duncan**
- **Scheffé**
- **LSD**
- **Bonferroni**

> 📌 실무에서는 보통 Duncan 또는 LSD를 간단 비교용으로 사용하고,
>
> **Scheffé / Bonferroni**는 보수적인 검정이 필요할 때 사용합니다.

### ④ 표 형식 선택

- **행 기준**
- **열 기준**

결과를 어떻게 배치해서 볼지 선택하는 옵션이며, 분석 결과 자체에는 영향 없음.

---

## 4. 분석 단계 (Step-by-step)

1. **분석 메뉴 선택**
   - ‘집단비교분석 > 일원배치분산분석’ 선택
2. **독립변수 선택 (집단 변수)**
   - 예: 영화관품질만족4 → 집단이 3개 이상이어야 함
3. **종속변수 선택 (분석 대상 문항)**
   - 예: 고객만족도4, 지속이용여부 등 점수형 문항
4. **사후검정 선택** (필요 시)
   - Duncan / Scheffé / LSD / Bonferroni
5. **표 형식 설정**
6. **분석 실행**

## 5. 결과 해석 (Interpretation)

일원배치분산분석은 아래 3가지를 중심으로 해석합니다.

---

### ✔ (1) 집단 간 전체 차이(F값, p값)

- **p &lt; 0.05** → 3개 집단 중 최소 1개는 다른 집단과 평균이 다름
- **p ≥ 0.05** → 전체적으로 유의미한 차이 없음

즉, 첫 단계는 “전체적으로 차이가 있는가?”를 판단하는 과정입니다.

---

### ✔ (2) 집단별 평균 비교

p값이 유의한 경우,

“어느 집단이 높은가 / 낮은가”를 확인합니다.

(예)

| 집단 | 평균 |
| ---- | ---- |
| 10대 | 3.2  |
| 20대 | 3.9  |
| 30대 | 4.1  |
| 40대 | 3.6  |

→ 30대가 가장 높은 만족도를 보임

---

### ✔ (3) 사후검정(Post-hoc)으로 구체적 차이 확인

ANOVA에서 유의하면 사후검정을 통해 아래를 확인합니다:

- 어떤 집단끼리 차이가 있는가?
- 어떤 집단은 서로 유사한가?
- 차이가 나는 집단 조합은 무엇인가?

(예)

- 30대 vs 10대: 유의
- 30대 vs 40대: 유의
- 20대 vs 40대: 유의하지 않음

이렇게 구체적인 그룹 차이를 확인할 수 있습니다.

## 6. 자주 묻는 질문 (FAQ)

### **Q. 독립변수는 왜 1개만 선택하나요?**

A. 일원배치(One-way)는 “하나의 요인(집단 변수)”만으로 집단 차이를 검정하는 분석입니다.

### **Q. 집단이 2개뿐이면 어떻게 하나요?**

A. 집단이 2개라면 t-검정이 더 적합합니다.

ANOVA는 3개 이상일 때 의미가 있습니다.

### **Q. 사후검정이 꼭 필요한가요?**

A. 전체 차이가 유의(p&lt;.05)한 경우에만 필요합니다.

그렇지 않으면 사후검정을 해도 의미가 없습니다.

### **Q. 어떤 사후검정을 선택해야 하나요?**

A.

- **쉽게 그룹을 비교하고 싶다면 → Duncan, LSD**
- **보수적인 검정이 필요하면 → Scheffé, Bonferroni**

## 7. 보고서 작성 활용 문장 예시

- “연령대에 따라 고객 만족도는 유의미한 차이를 보였다(p &lt; 0.05).
  사후검정 결과, 30대가 가장 높은 만족도를 보였고 10대와 40대보다 유의하게 높았다.”
- “이용빈도에 따른 추천 의향은 통계적으로 차이가 없었다(p ≥ 0.05).”
- “고객 유형별 요금 만족도 점수는 서로 다른 패턴을 보였고, 특히 프리미엄 이용 고객은 일반 고객 대비 높은 평가를 하였다.”
- “사후검정을 통해 20대와 30대 집단 간에는 차이가 없었으나, 30대와 50대 집단 간에는 유의미한 차이가 발견되었다.”
