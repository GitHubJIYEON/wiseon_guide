# 설문 프로젝트 만들기

## 개요

설문 프로젝트를 만들고 문항을 작성하여 설문을 구성할 수 있습니다.

## 주요 기능

- 신규 설문 만들기
- 템플릿 사용하여 만들기
- 설문 프로젝트 상태 관리
- 설문 문항 만들기
- 설문 문항 페이지 나누기
- 설문 시작/종료 안내문 설정
- 설문 미리보기

## 설문 생성

와이즈온에서는 새로운 설문 프로젝트를 몇 단계만으로 간단하게 생성할 수 있습니다.
설문 목적에 맞는 프로젝트를 만들고, 문항 작성부터 배포·분석까지 하나의 흐름으로 관리하세요.

3. **설문 프로젝트 정보** 입력
   - 설문명

   - 목표응답수

4. **완료** 버튼 클릭

→ 설문 생성 완료 후 **문항 작성** 단계로 이동

### 이런 경우에 적합합니다

- 처음부터 직접 설문 문항을 설계하고 싶은 경우
- 설문 문항이 명확하게 정해진 후 진행하려는 경우

> 💡 신규 설문으로 시작하면, 설문 문항 구조를 처음부터 자유롭게 설계할 수 있습니다.

### 이런 경우에 적합합니다

- 설문을 빠르게 시작해야 하는 경우
- 미리 구성된 문항 구조 사용
- 검증된 설문 구조를 활용하고 싶은 경우

> 💡 템플릿을 활용하면 설문 설계에 대한 부담을 줄이고, 보다 빠르게 설문을 시작할 수 있습니다.
