## 와이즈온 설문 흐름

<Steps>
### 설문 프로젝트 생성
**설문 생성 방법 선택**

- 신규 설문 프로젝트 만들기
- 템플릿으로 설문 만들기

**설문 문항 유형 선택 및 문항 구성**

- 문항 유형 : 객관식, 입력형, 평가형, 척도형, 설명형, 개인정보동의
- 문항 응답 옵션 설정
- 문항 페이지 설정 및 시작/종료 안내문 작성

**완성된 설문 미리 보기**

- 모바일·데스크톱 설문 미리보기

### 설문 배포

**완성된 설문을 응답자에게 전달**

- 익명 링크 배포
- 개인별 링크 배포

### 응답 수집 및 현황 확인

**설문 참여 현황과 응답 데이터를 실시간으로 확인**

- 설문 참여 현황 모니터링
- 실시간 응답 데이터 확인

### 설문 응답 데이터 활용

**응답 결과에 대한 다양한 분석이 보고서 생성으로 이어져 실제 업무 활용으로 연결**

- 응답 데이터 엑셀 다운로드(문항속성, 응답 데이터)
- 응답 데이터 기반 분석 진행

</Steps>
