## 개요

척도형 문항은 **행과 열로 구성된 표(Table) 형태의 문항**으로,  
여러 항목을 **동일한 기준(척도)** 으로 평가할 때 사용됩니다.  
만족도, 동의 수준, 비교 평가 등 **반복적 평가 구조**에 적합합니다.

---

## 척도형 문항이란?

척도형 문항은

- **세로(행)** 에 평가 대상(문항 항목)을 배치하고
- **가로(열)** 에 평가 기준(척도)을 배치하여

응답자가 각 항목을 동일한 기준으로 선택하도록 하는 문항입니다.

예)

- 항목: 서비스 품질 / 가격 / 편의성
- 척도: 매우 불만족 ~ 매우 만족

## 문항 작성 방법

1. **문항 제목 입력**

   어떤 기준으로 평가하는지 명확히 작성합니다.

   예)
   - `다음 항목에 대해 전반적인 만족도를 선택해주세요.`

2. **문항 설명 (선택)**

   평가 기준이나 응답 방법을 안내합니다.

   예)
   - `각 항목별로 가장 적절한 값을 선택해주세요.`

3. **세로 항목(행) 입력**

   평가할 대상 항목을 입력합니다.

   예)
   - 서비스 품질
   - 가격 대비 만족도
   - 전반적 경험

4. **가로 항목(열) 입력**

   공통으로 사용할 척도를 입력합니다.

   예)
   - 매우 불만족 / 불만족 / 보통 / 만족 / 매우 만족

---

## 응답 옵션 설정

척도형 문항에서는 아래 응답 방식을 선택할 수 있습니다.

- **단일**
  각 행마다 하나의 값만 선택
  (가장 일반적인 척도형)
- **다중**
  하나의 행에서 여러 값 선택 가능
  (복수 기준 평가 시 활용)
- **비교**
  항목 간 상대 비교에 활용
- **입력**
  선택 대신 직접 값을 입력하도록 설정

---

## Table 만들기 기능

여러 항목을 빠르게 생성하고 싶다면 **Table 만들기** 기능을 활용할 수 있습니다.

- 가로(열) 개수 입력
- 세로(행) 개수 입력
- 클릭 한 번으로 기본 테이블 생성

이후 각 항목의 텍스트를 원하는 내용으로 수정하면 됩니다.

---

## 추가 설정 기능

- **필수 문항 설정**
  모든 행에 대해 반드시 응답해야 설문 제출 가능

---

## 척도형 문항 작성 시 유의사항

- 척도 표현은 **양극단이 명확해야** 합니다.
  (예: 매우 불만족 ↔ 매우 만족)
- 모든 항목은 **동일한 기준**으로 평가할 수 있어야 합니다.
- 항목 수가 너무 많으면 응답 피로도가 높아질 수 있습니다.

---

## 이런 경우에 척도형 문항이 적합합니다

- 여러 항목을 **같은 기준으로 비교 평가**하고 싶은 경우
- 만족도, 동의도, 인식 수준을 구조적으로 수집하고 싶은 경우
- 보고서나 통계 분석에서 **행·열 기반 데이터**가 필요한 경우
- 반복적인 평가 문항을 간결하게 구성하고 싶은 경우

---

## 정리

척도형 문항은 **평가 대상의 일관성 + 명확한 척도 기준**이 핵심입니다.  
표 형태의 구조를 활용해 응답자에게는 쉽고, 분석에는 강한 설문을 만들어보세요.
