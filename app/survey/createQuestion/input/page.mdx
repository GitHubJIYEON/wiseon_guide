## 개요

입력형 문항은 응답자가 **직접 내용을 입력**하는 방식의 문항입니다.  
자유로운 의견, 수치 정보, 날짜, 연락처 등  
**정형화된 선택지로 표현하기 어려운 정보**를 수집할 때 적합합니다.

---

## 입력형 문항이란?

입력형 문항은 질문에 대해  
응답자가 **텍스트 또는 숫자를 직접 입력**하도록 하는 문항입니다.

- 응답자의 생각이나 정보를 자유롭게 수집할 수 있고
- 개인정보, 수치 데이터 등 정확한 값을 받을 수 있습니다.

---

## 문항 작성 방법

1. **문항 제목 입력**

    응답자가 무엇을 입력해야 하는지 명확히 작성합니다.

    예)
    - `현재 사용 중인 서비스의 불편한 점을 자유롭게 작성해주세요.`
    - `연령을 입력해주세요.`

2. **문항 설명 (선택)**

    입력 기준이나 형식 안내가 필요한 경우 활용합니다.

    예)
    - `숫자만 입력해주세요.`
    - `단위는 ‘년’ 기준입니다.`

3. **입력 영역 설정**

    입력 방식과 단위를 설정할 수 있습니다.
    - 한 줄 / 여러 줄 입력 선택
    - 단위 텍스트 설정 (예: 만, 세 등)

---

## 응답 옵션 설정

입력형 문항에서는 입력 데이터 유형에 따라 아래 옵션을 선택할 수 있습니다.

- **문자**
  자유로운 텍스트 입력
  (예: 의견, 사유, 건의사항)
- **숫자**
  숫자만 입력 가능
  (예: 나이, 금액, 횟수)
- **종합**
  문자 + 숫자를 함께 입력
  (예: 주소 일부, 코드 입력)
- **연락처**
  전화번호 형식 입력
  (예: 010-0000-0000)
- **날짜**
  날짜 선택 또는 입력
  (예: 방문일, 이용 시작일)

---

## 추가 설정 기능

- **필수 문항 설정**
  응답자가 반드시 입력해야 설문을 제출할 수 있습니다.
- **자동 보기 번호**
  문항 번호를 자동으로 표시할 수 있습니다.

---

## 입력형 문항 작성 시 유의사항

- 질문은 **구체적이고 명확하게** 작성하는 것이 좋습니다.
- 너무 긴 자유 입력은 응답자의 부담을 줄 수 있으므로
  필요한 경우 **입력 범위를 안내**해주세요.
- 개인정보를 수집하는 경우
  반드시 **개인정보동의 문항**과 함께 사용하는 것을 권장합니다.

---

## 이런 경우에 입력형 문항이 적합합니다

- 응답자의 **자유 의견**이나 상세 설명이 필요한 경우
- 연령, 금액, 날짜 등 **정확한 값**을 수집해야 하는 경우
- 선택지로 표현하기 어려운 정보를 수집할 때
- 후속 분석이나 검토가 필요한 서술형 응답이 필요한 경우

---

## 정리

입력형 문항은  
**명확한 질문 + 적절한 입력 유형 선택**이 핵심입니다.  
설문의 목적에 맞게 입력 방식을 설정해  
보다 정확하고 활용도 높은 데이터를 수집해보세요.
